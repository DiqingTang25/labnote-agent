# LabNote Agent 使用指南

LabNote Agent 是一个 AI 驱动的智能实验记录系统。你只需要**上传实验文件**，AI 会自动完成解析、分类、校验和结构化入库。本文档从用户视角介绍核心工作流。

---

## 1. 核心概念

### 你不需要填表

传统电子实验记录本（ELN）要求你手动填写几十个字段——实验目的、设备型号、样品编号、试剂CAS号……LabNote 反过来了：**你上传文件，AI 提取所有信息，自动生成结构化卡片。** 你只需要审核和微调。

### 模板 = 视图，不是约束

系统内置 25 个专业实验模板（从 DFT 计算到电化学测试），但模板**只决定数据怎么组织和展示**，不限制你能记录什么。AI 提取到的任何信息——即使模板中没有定义——都会保留在卡片底部的「未归类数据」区域，绝无丢弃。

### 实验卡片 = 结构化数据 + 原始文件

每张卡片包含两部分：
- **结构化属性**（properties）—— 按实验类型分组的字段值
- **原始文件**（attachedFiles）—— 你上传的仪器数据、实验笔记、图像

## 2. 快速开始

### 第一步：上传文件

打开 LabNote，你会看到主页的拖拽上传区域。支持的文件类型：

| 类型 | 格式 | AI 处理方式 |
|------|------|-----------|
| 文本笔记 | `.txt`, `.md`, `.log` | DeepSeek V4 文本理解 |
| 数据表格 | `.csv` | 列统计分析 + DeepSeek 语义识别 |
| 实验图像 | `.png`, `.jpg` | Qwen3-VL 视觉识别（SEM/TEM/仪器读数） |
| 仪器日志 | `.json`, `.xml` | 结构化数据直接映射 |

**拖拽一组文件到上传区**（比如：一个实验笔记 `.md` + 一个数据表 `.csv` + 一张 SEM 图 `.png`），AI 会把它们关联到同一张实验卡片。

### 第二步：等待 AI 解析

上传后，你会看到进度条显示三个步骤：
1. **读取文件** — 提取文本内容
2. **AI 识别** — 每个文件独立分析，提取结构化信息
3. **去重合并** — 把多个文件的结果合并成一张完整的实验卡片

### 第三步：审核卡片

解析完成后，工作台中央会显示实验卡片。卡片上方是基本信息（名称、时间、操作人），下方按**专业分组**展示提取的字段：

```
[基本信息]
  实验名称: ResNet-50 CIFAR-10 训练
  时间: 2026-08-10 14:30
  操作人: 张三

[数据集]
  数据来源: Kaggle CIFAR-10
  样本数: 50000
  划分比例: 8:1:1

[模型]
  架构: ResNet-50
  优化器: AdamW
  学习率: 0.001

[评估指标]
  验证准确率: 94.2%
  F1 Score: 0.937

[未归类数据]          ← AI 提取到但模板未覆盖的信息
  augmentation: RandomCrop + HorizontalFlip
  warmup_epochs: 5
```

每个字段旁边可能有标记：
- **🤖推断** — AI 根据上下文推断的，建议人工确认
- **⚠️** — 值超出常见范围（比如温度 500°C 对于水热反应偏高），但不一定错误
- **🔴** — 违反物理约束（比如产率 120%），需要修正

### 第四步：微调并保存

点击任意字段即可编辑。你也可以：
- **一键补全** — 让 AI 根据已有信息推断缺失字段
- **重新解析** — 如果发现遗漏，让 AI 重新分析原始文件
- **添加自定义字段** — 模板中没有的字段可以随时添加
- **切换模板** — 如果 AI 分类不够精确，手动切换到更合适的模板

保存后，卡片数据写入云端数据库。所有修改都有**审计日志**可追溯。

## 3. 模板系统怎么帮你

### AI 自动匹配

上传文件时，AI 会根据文件名和内容自动判断实验类型，匹配最合适的模板：

| 你上传的文件包含... | AI 匹配的模板 |
|-------------------|------------|
| `VASP`, `encut`, `kpoints`, `POSCAR` | DFT 结构优化 |
| `gromacs`, `rmsd`, `TIP3P`, `solvation` | 蛋白质水中平衡模拟 |
| `learning_rate`, `batch_size`, `accuracy`, `ResNet-50` | 图像分类模型训练 |
| `XRD`, `2theta`, `Cu K-alpha`, `Rietveld` | XRD 表征测试 |
| `水热`, `反应釜`, `保温`, `产率` | 水热/溶剂热合成 |

如果 AI 判断不了，使用「通用实验」模板——所有信息都会被保留和展示。

### 物理约束自动校验

保存时，系统自动检查数值的合理性：

- **硬边界（拒绝入库）**：温度 < -273.15°C、产率 > 100%、泊松比 > 0.5
- **软边界（警告）**：截断能 1500 eV 虽然可能（手册允许 100-2000 eV），但远超常见范围（300-600 eV）

所有约束规则都标注了来源（VASP manual、NOMAD Metainfo、Allotrope ASM 等），你可以点击查看依据。

### 字段从数据中自动涌现

随着同类型实验积累，系统会自动发现"候选字段"。比如如果你和同事的 5 个 ML 训练实验都在 `extra` 里记录了 `warmup_epochs`，系统会在新建 ML 实验时建议：「`warmup_epochs` 出现在 80% 的同类实验中，是否加入模板？」

## 4. 知识库问答（RAG）

右侧面板的知识库问答可以跨实验检索信息。你可以用自然语言提问：

> "哪次实验用了 AdamW 优化器？"
> "上次 XRD 检测出了什么物相？"
> "DFT 计算中哪次结构的带隙最小？"

系统会搜索所有你的历史实验，用 AI 生成带引用来源的回答。

---

## 5. 导出与复现

工作台工具栏提供三种导出：
- **Markdown** — 实验报告草稿
- **JSON** — 完整结构化数据（可导入其他工具）
- **PDF** — 打印版实验记录

点击「复现包」可一键下载实验卡片 + 原始文件 + Methods 草稿的打包文件。

## 6. 常见场景

### 场景 A：记录一次 DFT 计算

1. 把 VASP 的 `INCAR`、`POSCAR`、`OUTCAR` 片段拖入 LabNote
2. AI 自动匹配「DFT 结构优化」模板
3. 自动提取：交换关联泛函、截断能、K 点、力收敛标准、弛豫后总能
4. 系统校验：截断能 520 eV 在常见范围（300-600）→ ✅
5. 保存。卡片可导出为论文 Methods 段落的草稿

### 场景 B：记录一次失败的合成实验

1. 把实验笔记 `.md`（含温度曲线、异常观察）拖入
2. AI 提取反应条件 + 异常备注
3. 你把产率手动填入 12%
4. 系统校验：产率 12% 在合理范围（0-100%）→ ✅
5. 在「异常与备注」区域记录失败原因分析
6. 保存。后续 RAG 问答可以搜到：「找出所有产率低于 20% 的水热实验」

### 场景 C：对比两次实验参数

1. 在工作台打开两张实验卡片
2. 导出 JSON，用脚本 diff 关键参数
3. 或在知识库中提问：「实验 A 和实验 B 的温度条件有什么不同？」

## 7. 数据安全

- **数据隔离**：每个用户只能访问自己的实验（Supabase Row Level Security）
- **脱敏扫描**：上传前自动检测身份证号、手机号等敏感信息
- **审计追踪**：所有修改操作都有不可篡改的日志（符合 FDA 21 CFR Part 11）
- **API Key 保护**：AI 调用通过服务端代理，浏览器从不接触 API Key
